# Contributing

Thank you for your interest in the AI Exosuit MK-7 project.

This repository is currently maintained by the Cybernetic Biological Initiative.

At this stage, development is directed by the project maintainer while the core architecture and visual identity are being established.

Constructive feedback, issue reports, documentation improvements, and respectful discussions are welcome.

Please open an Issue before proposing significant changes so ideas can be discussed first.

Thank you for supporting the project.
